### **.gitignore and requirements.txt**

`.gitignore`
A file you create in your project that tells Git which files you want excluded from being tracked or modified. It keeps unnecessary files from being synced/committed to your repository. For example, in my `.gitignore` file,  `.history/Shipping – Calculator_ 20260319224038.html` will no longer be appear in my untracked files.


`requirements.txt`

A file you upload to your repository listing all the packages needed to get your project up and running. For example, if I downloaded a project that you have uploaded to your GitHub I would then use the `requirements.txt`
file to install every package you used with one command line.
It is typically used in Python to list all the packages your project depends on to run by typing `pip instal -r requirements.txt` into the terminal.
