## Unshift is used to add new items at the begingining of an array. for example

`const cFGDegree = ["Software and Data Engineering", "Data Science"];`
`cFGdegree.unshift = ["Full-Stack Development","Product Management"];`

## The new arrray would look like this

`cFGDegree = ["Full-Stack Development", "Product Management", "Software and Data Engineering", "Data Science"];`

## with the new items added at the start of the array replacing index position `[0]` and `[1]` form Software and Data Engineering", "Data Science" to "Full-Stack Development", "Product Management".
